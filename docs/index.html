Same setup · different result

Where the randomness lives

Both models are random, but the randomness enters at different points. Nothing below is cherry-picked — these are the same networks you have been scrubbing through.

One image, encoded five times

The encoder does not output a point — it outputs a distribution. Encode the same image five times and you get five slightly different z, so five slightly different reconstructions. Only the second uses the mean, with no sampling at all.

Three runs, three starting noises t = 199

Same trained network, same schedule, same number of steps. The only difference is the random noise each run started from — and that alone decides which digit appears. Drag the slider above to watch all three resolve at once.

How the input is compressed

Every station below is a real layer from the trained models, with its actual shape and activations. Tile size follows the spatial dimension; bar height follows how many numbers the layer holds, on a log scale shared by both rows.

Channel A

VAE encoder

The count is not monotonic: the first convolution makes it larger, because the spatial size halves while the channels grow from 1 to 32. The real compression happens at the dense layers, and the encoder stops at an embedding.
